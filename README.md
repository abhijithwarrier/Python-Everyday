## 🚀 Getting Started

Clone the repository and open its folder:

```bash
git clone https://github.com/abhijithwarrier/Python-Everyday.git
cd Python-Everyday
```

Run an example:

```bash
python fstrings_clean_reports.py
```

Use `python3` if that is the Python command on your system.

The f-strings example requires **Python 3.6 or later** and no external packages. Any additional requirements for future examples will be documented in their scripts.
